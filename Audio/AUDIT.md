# W11 전수 점검 — 2026-09-14

현재 Unity/Wwise 실행 경로, 전체 C# 컴파일, Unity 메타데이터, W11의 자산 참조, 원본 음원·SoundBank, 빌드 및 전달 도구를 점검했습니다. 보존된 브라우저 데모도 빌드·단위 검사를 실행했습니다.

## 발견하여 수정한 항목

1. **기본 빌드 장면이 초기 무음 데모였음:** 기본 Scene List를 W11로 변경했습니다. W10과 과거 장면은 보존했습니다.
2. **빌드 검사가 Windows x64 외 모든 대상을 Mac으로 판단했음:** Windows x86/x64와 Mac을 명시적으로 분류하고, SDK·Bank가 없는 대상은 거부합니다. 빈 파일·잘린 Bank와 잘못된 헤더도 빌드 전에 검사합니다. 초기화·리스너·음원 컴포넌트의 활성 상태와 참조도 확인합니다.
3. **SDK 비활성 컴파일 회귀:** SDK 전용 녹음 변수를 조건부 컴파일 안으로 옮겨 경고를 오류로 처리하는 검사 실패를 해결했습니다. W11의 폐기 예정 Unity 검색 API 사용도 갱신했습니다.
4. **Wwise 설치 후 전달 도구가 실패했음:** 제외 대상으로 지정한 SDK 문서·디버그 심볼을 필수 파일로 요구하지 않도록 수정했습니다. Mac 네이티브 bundle은 내부 바이너리를 보존하고, Unity가 실제로 사용하는 bundle 루트의 `.meta`를 검사합니다. 일반 자산·폴더의 메타데이터 검사는 유지합니다.
5. **실행·인계 안내가 과거 상태였음:** W11 브랜치를 지정하는 clone 명령, 기본 빌드 장면, 실제 푸시 완료 커밋과 최신 검사 결과를 반영했습니다. 특정 `/tmp` 환경에 의존하던 WAAPI 도구 실행 안내도 수정했습니다.

## 확인 범위와 남은 사항

- Windows 실행 파일은 이 Mac에서 직접 실행하지 않았습니다. 실제 Windows의 실행·소리 출력과 사람이 듣는 최종 음량·음색 확인은 남아 있습니다.
- 이전에 확인한 일반 Unity Editor 렌더링 화면은 별도 기록입니다. 이번 88개 실행 검사는 그래픽 없이 수행했으며, 시각 품질이나 FPS를 다시 평가한 결과가 아닙니다.
- 천둥 3개와 concrete 발소리 6개는 의도적으로 라이브러리에 보관했습니다. 천둥·섬광 동기화와 concrete 표면 구분은 추가 기능입니다.
- 브라우저 빌드의 500kB 초과 JavaScript 청크 알림은 남아 있습니다. 보존된 데모의 성능 개선 항목이며 빌드 실패는 아닙니다.

전수 점검 수정과 보고서는 `feat/wwise-w11` 브랜치에서 함께 관리합니다. Wwise 연결의 기준 커밋은 `15159e3`입니다. 작업 시작 전에 있던 사용자 재질 수정 두 건과 PackageManager 설정은 보존했으며 이번 점검 커밋에는 포함하지 않습니다.
