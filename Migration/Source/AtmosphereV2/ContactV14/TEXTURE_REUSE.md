# Existing licensed texture reuse

Native rendering is intended to reuse the project's existing Rock05 stone material, with the exported per-vertex neutral/brown/olive multipliers and new closed geometry. No texture is generated, downloaded, uploaded or modified by ContactV14. The existing measured grain is used for stone fragments and dark mineral contact deposits; the small olive wall pocket is an art-directed moss suggestion, not a claim of a separately captured moss surface.

The existing map set is recorded in `Migration/Source/AtmosphereV2/PhotographicStone/provenance-rock05.json`: Poly Haven Rock05, author Rob Tuytel, CC0, source https://polyhaven.com/a/rock_05. Its four original map hashes and source URLs remain in that preserved provenance file. The source review previews use neutral matte materials for geometry visibility, so actual native Rock05 behavior still requires the parent's Unity comparison.
