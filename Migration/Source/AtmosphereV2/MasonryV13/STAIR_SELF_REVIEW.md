# Stair source self-review

The matched `stairs-before-clay.png` and `stairs-after-clay.png` were opened directly at 1536×1024 after the final Manifold build. The after image retains all ten rows and ninety blocks, including the first-row second block lost by the rejected Exact-Boolean pass. Thirty noses now show broader unequal shallow fracture planes. Wider interior joints make the existing lateral stagger more legible. The stair flight width, height sequence and broad silhouette remain unchanged.

This is a useful local geometry improvement, not a whole-stair material or lighting solution. Large tread and riser planes still dominate, and the neutral clay view still reads as deliberately constructed modular stone. It cannot establish how the native Rock05 material, wetness and opposing light directions will read together. The candidate41 warm-riser/cool-tread cause described in `CANDIDATE41_AUDIT.md` remains a separate native rendering task.

The export contains 64,780 triangles, 1,556 more than V11. Independent JSON checks passed with no reversed normal dots or degenerate triangles, finite unit normals and unchanged world bounds. Per-stone build checks preserve volume and connected-component count; the independent output check preserves all ninety original neutral color identities. The exact V11 removal manifest still applies. No Unity scene, material, source V11/V12 asset or other project was edited.

Source geometry is ready for the parent's native comparison. It is not a new independent Unity score, Tier3 acceptance, performance result or user adoption.
