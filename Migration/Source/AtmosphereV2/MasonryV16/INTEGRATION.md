# MasonryV16 source integration contract

This package changes no Unity file. Native Unity world coordinates are used for the flight and facade. The eight hero replacements are normalized local Unity coordinates and require the exact original TRS from `hero-overrides.json`.

`stairs-v16-mesh.json` replaces only the current V13 combined stair asset, at identity. Rows 0, 2, 4, 6 and 8 are rebuilt from closed lithic blocks. All 45 V13 bodies in rows 1, 3, 5, 7 and 9 retain their exact positions, normals, UVs, vertex colors and triangle order; the independent checker compares every referenced attribute. The existing V11 removal manifest for 278 browser stair pieces stays active. The ten internal support boxes remain. Do not remove or merge them with the source export.

`hero-overrides.json` adds eight lower visible exact instances to the existing V13 overrides; it does not replace or delete the earlier eight. These target four flame-pier faces, two lower portal pier blocks and two nearby cheek caps. Two are trim-material instances. Preserve each original material, color and TRS; apply each normalized override after the standard V12 selection fallback. Do not enforce the old eight-total override count after adding this separate set. The new set must match exactly eight unique original identities.

`facade-removal-manifest.json` selects 63 decorative facade skins over world Z approximately [-3.805,4.705], Y [-3.415,-0.285]. All original core foundation shafts, dark structural masses and skins outside the manifest remain. Of these skins, 54 pass the current `InstallStone` Y >= -3 filter; nine centered at Y=-3.2 are restored by `RestoreFoundations`. Both paths must omit their exact manifest identities before AppendStone, while retaining original selected-list, chunk and loop seed numbering. Removing only the 54 visible-path instances leaves the lowest old stripe behind. Removing an entire restored batch would wrongly remove protected foundation geometry.

Import `facade-v16-mesh.json` at identity using the existing Rock05 stone material and supplied neutral vertex colors. Larger blocks use different widths and staggered bond positions across seven bands, with two actual double-height header stones interrupting the horizontal joint at separate locations. The exact body count is in `source-build.json`. The outer lithic faces have no more than 8 cm extra outward allowance from the old X=-9.72 extent; internal cores are untouched. This small outer allowance gives fracture surfaces room without revealing black internal masses. It is not permission to move the wall or navigation boundary.

Source export attributes include finite positions/normals/UV/RGBA and positive triangle winding, with independently checked closed positive-volume bodies. The final mesh statistics and hashes are in `independent-validation.json`. `build_source.py` uses standard Python; `validate_source.py` uses NumPy and was run with Blender's bundled standalone Python, not by launching Blender.

Preview material uses the existing licensed Rock05 maps. Blender source lights are held identical across each pair but do not reproduce the Unity HDR environment or shader. Native full-camera comparison is still required before adoption. PavingV15, TreeV12 and ContactV14 are retained unchanged as context. The non-instanced arch ring, character and fire effects are not recreated by this source preview.
