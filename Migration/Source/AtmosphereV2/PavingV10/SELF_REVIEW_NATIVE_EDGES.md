The narrow prior face channels did not interrupt that reading at scene scale. This pass targets the outlines, while the parent separately adjusts excessive specular response.

Preserved the current source package under `native34-preserved/` and the existing evidence under the matching evidence directory. `wear_native_edges_v10.py` reads that frozen blend. It retains the unequal slab layout and inherited interior fracture vertices, replacing perimeter bands with two or three localized, unequal, broad recesses per eligible stone. The method does not add random dents around the full perimeter or wave the complete surface.
