# Paving V12 bounded hybrid

Native41 full, concept, verdict7 and source AO were directly inspected. The continuous 88mm grid preserves the photo but does not retain large slab edge topology or independent planes. The next change is 24 source-matched, separately meshed stone bodies in the lower-frame foreground, over a continuous recessed stone/soil bed. This is not another global UV-scale pass.

Original Tiles130 maps and PavingV11 remain read-only. Source corners and slab seeds are manually identified on the actual Color/AO images. AO-dark boundaries and local height gradients refine those source-space contours; absolute height thresholding is unsuitable because the scan has unequal base heights. Marker/contour constraints also avoid treating every small crack as a separate pebble. OpenCV's official watershed documentation explicitly describes unconstrained over-segmentation and marker control: https://docs.opencv.org/4.x/d3/db4/tutorial_py_watershed.html . This package uses hand-selected source contours with bounded edge refinement, not a claim that an automatic segmentation recovered perfect archaeological stone boundaries.

Keep each hero stone initially in the same photo-space position: cap, bevel and side UVs remain attached to the same source slab. This avoids the old crack/geometry mismatch and avoids random placement of new stones over visible ghosts of the old stones. Give each cap an independent plane; retain only1-3mm scan residual on that plane, then create a real broken bevel and descending side. Recess the bed immediately underneath and alongside that stone. Source soil/fragment pixels remain at joints. Perimeter widths are unequal, approximately6.5-10.5cm; their projected2-6pixel appearance is inspected at the native camera. Following root's later water-contact clarification, some hero planes sit above and some below waterY=-.004; source bed retains its40mm art amplitude. The former world footprint/rear stair void is preserved. One third of chosen bodies shrink16-18% on one axis while their attached source UV undergoes the inverse transform; this local UV is not equivalent to a new global worldUV formula.

The first bounded package prioritizes24 readable large source stones across the lower half of the actual camera. It does not promise a global perfect retopology of every stone or removal of every baked fine crack. Tiny crack geometry is subordinate to the new independent planes and broad arrises; any further Color/normal micro-crack attenuation must remain aligned and use a derived artifact, never mutate the downloaded originals. Source-photo topology is preferred over inserting a new regular grid.

Geometry budget: reduce only the unremarkable continuous bed sampling density, and spend triangles on closed slab contours/caps/bevels. Keep whole-ground total below160k. Export identity Unity positions, geometry normals, source-aligned UVs, white vertex colors and positive face-cross/normal convention. Validate each body is closed, bed boundary-only open, finite attributes, valid indices, positive winding, exact coverage bounds and source hashes. Neutral and actual4K textured Blender comparisons against V11 are required before native handoff. Native water/roughness/color and final visual acceptance remain root's work.
