# 직선형 맵 이미지 검토 — L01

사용자 요청: 큰 통합 맵의 구성을 단순한 직선형으로 바꾸고, 걸으며 자연스러운 환경 변화만 감상한다. Higgsfield로 같은 게임 시점의 다섯 장을 만든다.

범위는 이미지 생성과 검토다. 이 결과는 Unity 화면이나 구현된 새 맵이 아니다. 약 300m는 배치 제안이며 이미지로 검증한 거리가 아니다. E02 실행본, F01 중간 후보, F02 미컴파일 초안의 상태를 변경하지 않았다. 기존 세 목표 이미지도 교체하지 않았다.

## 순서

1. `01-waterside.png` — 맑은 물가와 작은 석교.
2. `02-damp-wood-r1.png` — 젖어가는 숲길. 초기 `02-damp-wood.png`는 기록 보존.
3. `03-rainy-abbey.png` — 직선 길 옆의 작은 폐허와 비.
4. `04-frost-transition.png` — 젖은 땅, 혼합 식생, 부분 적설.
5. `05-snow-pass.png` — 눈 덮인 고갯길.

## 직접 이미지 검토

- 초기 다섯 원본을 모두 직접 열어 확인했다. 출력은 각각 2048×1360 PNG다.
- 같은 방향의 직선 동선, 비슷한 게임 카메라와 캐릭터, 기존 석조/식생 계열이 유지되었다. 독립 생성한 이미지이므로 정확히 동일한 카메라 변환이나 캐릭터 픽셀 크기를 보장하지 않는다.
- 초기 숲길이 이미 폐허처럼 어둡고 젖어 있어, 배치를 보존하면서 중간 밝기와 부분 젖음으로 한 번 보정했다. 수정 원본도 직접 열어, 밝기 증가와 따뜻한 잔광/마른 지면이 확인되어 다섯 장 중 두 번째로 선정했다. 사용자 채택은 별도다.
- 서리길의 적설과 노출 지면 대비, 설산의 바위 높이와 길 폭은 실제 배치 때 조정할 여지가 있다. 스틸 이미지는 연속 날씨 전환 속도, 이동 거리, 접지, 성능의 증거가 아니다.
- 모델: Higgsfield의 GPT Image 2, 2k/high, 3:2. 기존 세 목표 이미지를 참조했다. 원본 픽셀 편집 없음.
- `request.json`은 제출 전 요청 기록이다. 실제 작업 ID/완료 상태는 `submission.json`, `completed-jobs.json`, `delivery.json`에 있다. 숲길 보정은 별도 `02-revision-*` 기록이다.

총 여섯 번 생성했고, 다섯 장을 최종 검토 후보로 전달한다. 사전 견적 합계39크레딧과 실제 잔액 감소2378→2339(39)가 일치한다. `final-delivery.json`이 최종 전달 순서와 파일의 기준이다. 정확한 최초 프롬프트는 `request.json`, 숲길 보정 프롬프트는 `02-revision-request.json`에 보존했다.

최종 시각 채택과 Unity 구현은 이번 이미지 생성 범위에 포함하지 않는다.
