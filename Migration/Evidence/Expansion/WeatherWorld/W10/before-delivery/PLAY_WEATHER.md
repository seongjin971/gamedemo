# VESPER — 구조물 보수·더 강한 섬광 W09

`PLAY_VESPER_WEATHER.cmd`를 실행하면 **1920×1080 전체화면**으로 플레이합니다.

순서: 강가 → 비 오기 전 어두운 숲 → 비 오는 숲 → 천둥 섬광이 비치는 폐허 → 밤 눈보라 설산.

- 비 구간 앞 숲을 48m 늘렸습니다. 먼저 어두워지고, 뒤에서 비가 서서히 시작됩니다.
- 폐허 지붕을 벽·기둥에 맞춰 연결하고 목재 지지를 보완했습니다. 쉼터 안에서는 지붕이 투명해져 캐릭터가 보입니다.
- 천둥 최고점은 W06보다 더 밝습니다. 화면 영역별 평균 픽셀 밝기 약1.44~1.50배이며 물리 광도 배수는 아닙니다.
- 천둥은 방향 없이 화면 전체가 두 번 짧게 번쩍이고 원래 어둠으로 돌아옵니다. 번개 선은 없으며, 다섯 번에 한 번은 더 강하게 비칩니다.
- 설산의 잔눈 발생량을 2.5배, 가까운 눈발을 약 2.7배로 늘렸습니다. 차가운 밤 조명과 바닥·공중 눈가루는 유지했습니다.
- 평상시 어두움은 기존 비 구간 조명을 기준으로 잡았습니다. 음향은 없습니다.

클릭 이동 / 드래그 시점 회전 / 휠 확대 / Shift 달리기 / R 시작점 복귀 / Alt+F4 종료.

녹화할 때는 기존 게임을 닫고 `RECORD_VESPER_WEATHER.cmd`를 실행합니다. 이미 설정된 OBS **VESPER FHD 30** 프로필을 사용합니다. **Ctrl+Shift+F9** 녹화 시작, **Ctrl+Shift+F10** 중단. OBS 설정 자체는 변경하지 않았습니다.

이전 날씨 버전은 `PLAY_VESPER_WEATHER_W06.cmd`와 `PLAY_VESPER_WEATHER_W05.cmd`, 기존 길 수정 버전은 `PLAY_VESPER_ROAD.cmd`로 실행합니다. 새 W09는 기존 실행본·장면·공유 자산을 보존한 별도 후보입니다.

검증 및 실제 전후 이미지: [W09 보고서](Migration/Evidence/Expansion/WeatherWorld/W09/REPORT.md). 독립 평가에서 이번 두 변경을 확인했으며, 전체 참고 이미지 완전 일치와 사용자 최종 시각 채택은 별도입니다.
