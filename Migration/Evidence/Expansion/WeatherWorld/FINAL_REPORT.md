# VESPER 이전 날씨 변경 — W05 전달

2026-09-11. 사용자가 재차 요청한 **눈에 띄는 결과가 나오면 마무리** 기준으로 W05를 전달한다. 실제 설치된 Dream Loop Pro의 화면 비교와 독립 평가를 적용했다. 참고 이미지와의 완전한 일치나 사용자 최종 수락을 선언하지 않는다.

## 실행

- **전체화면 FHD:** 프로젝트 루트 `PLAY_VESPER_WEATHER.cmd`.
- **기존 OBS 설정으로 녹화:** 기존 게임을 닫고 `RECORD_VESPER_WEATHER.cmd`. Ctrl+Shift+F9 시작 / Ctrl+Shift+F10 중단. OBS 설정은 이번 작업에서 변경하지 않았다.
- 실행본: `Unity/Vesper/Builds/VesperWeatherWorld_W05/VesperLinear.exe`.
- 장면: `Unity/Vesper/Assets/Vesper/Scenes/Expansion/VesperWeatherWorld_W05.unity`.
- 기존 `PLAY_VESPER_ROAD.cmd`와 `RECORD_VESPER.cmd`는 계속 L09를 사용한다.

## 적용 내용

1. **비 오기 전 어두운 숲 48m 추가.** 기존 48~90m 부근을 90m 길이로 확장하고, 이후 지형/랜드마크를 48m 뒤로 연결했다. 모델의 비율은 유지하고, 같은 자작나무·바위·풀 자산을 보강했다. 어두워짐과 강수량을 분리해 어두운 마른 숲을 지난 뒤 빗줄기가 시작된다. 바람에 날리는 소량의 잎을 추가했다.
2. **번개 선 없는 천둥 섬광.** v03의 먼 빛을 기본으로, v02의 넓은 강한 빛을 드물게 사용한다. 원거리 지면/공기의 빛과 수관을 분리해 나뭇잎이 하얗게 씻기는 결함을 줄였다. 설정상 간격은 약 8~17초, 다섯 번에 한 번 강한 이벤트, 짧은 복수 펄스 후 원래 조명으로 돌아간다. 이 주기 수치는 코드 설정이며 장시간 실제 녹화로 빈도를 측정한 결과는 아니다.
3. **설산을 밤 눈보라로 변경.** 차가운 밤 조명, 부드러운 그림자, 크기가 다른 사선 눈발, 바닥 눈가루와 별도 공중 눈안개를 사용한다. 기존 길·바위·설목 배치는 유지했다.
4. **평상시 비 구간의 조명을 기준으로 유지, 음향 없음.** 실제 런타임 오디오 소스 0개.

## 시각 평가와 한계

독립 전체 이미지 일치도: W01 5.49 → W03 5.78 → W04 5.91 → **W05 6.04/10**. 최종 눈보라 항목은 **6.85/10**이며, 눈과 공중 눈가루 강화 및 플레이어/길 가독성 유지를 확인했다. [최종 독립 평가](W05/judge.md). 이 점수에는 보존한 수목·바위·길·폐허 자산과 AI 참고 이미지 사이의 차이도 포함된다. Pro의 8점 완전 일치 기준 통과와는 구분한다.

기존 자산의 세부 형태, 지면/젖은 표면의 미세 반사, 참고 이미지 수준의 풍부한 수관과 눈안개에는 차이가 남는다. 사용자 요청에 따라 눈에 띄는 변경을 구현한 이 후보에서 작업을 끝내며, 최종 미적 채택은 사용자 확인이 필요하다.

W02는 눈 구간 진입 중 네이티브 실행 중단이 발생한 후보로 보존했다. 눈발별 물리 충돌을 제거한 W03 이후에는 캡처와 최종 W05 대표 걷기/성능 실행을 완료했다. 이전 충돌 기록은 원인 확정이나 완전한 장시간 안정성 보증으로 바꾸어 쓰지 않는다.

W04의 내부 `WEATHER_PREVIEW.mp4`는 약 7.64Hz 스크린샷을 시간에 맞춰 연결한 효과 검토용이다. 부드러운 녹화 전달본이 아니므로 클라이언트 전달용 영상은 새 OBS 녹화 실행기를 이용한다.
