# W06 — 더 많은 눈발과 전체 화면 섬광

**두 요청 모두 독립 시각 평가 PASS. 눈에 띄는 결과가 나오면 마무리하라는 사용자 기준으로 종료한다.** 실제 설치된 Dream Loop Pro의 구현 → 실제 Unity 화면 → 새 독립 평가 과정을 적용했다. 기존 생성 참고 이미지를 유지하고, 섬광 방향은 최신 사용자 지시를 우선했다. 새 이미지 생성·결제·음향 추가는 없었다.

실행: [FHD 전체화면](../../../../../PLAY_VESPER_WEATHER.cmd). 이전 W05는 [이전 버전 실행](../../../../../PLAY_VESPER_WEATHER_W05.cmd)으로 보존했다. 기존 OBS 실행 버튼은 현재 W06을 연다. 이번에는 OBS 설정 변경이나 새 녹화 테스트를 하지 않았다.

## 눈에 보이는 변경

- 잔눈 발생량 2,000 → 5,000/초, 가까운 눈발 450 → 1,200/초. 발생량 설정 기준 2.5배/약2.7배이며, 입자 수 제한도 올렸다. 크기와 불투명도를 소폭 높여 작은 FHD 눈발이 잘 보이게 했다. 실제 실행 중 잔눈9,594개, 가까운 눈발2,303개를 확인했다. 화면에 보이는 입자 수는 위치와 가림에 따라 다르다.
- 앞쪽 지면·안개에 집중되던 섬광 위치 계산을 제거했다. 태양 방향과 강도는 점멸 동안 그대로이고, 전체 화면 노출과 얇은 균일한 밝기 효과가 함께 점멸한다. 기본 이벤트도 전체 화면에 적용되며, 드문 강한 이벤트는 더 밝다. 번개 줄기 없음.
- 한 이벤트는 약0.10초/0.34초에 두 번 밝아지고 빠르게 감쇠한다. 실제 프레임 기록에서 최대1.0/두 번째 약0.745, 1초 뒤 거의0으로 복귀했다. 이벤트 사이에는 기존 어두운 조명으로 돌아온다. 8~17초 간격과 다섯 번째 강한 이벤트는 코드 설정이며 장시간 실측 빈도로 주장하지 않는다.
- 맵·직선 길·플레이어·평상시 조명·기존 눈안개와 바닥 눈가루는 유지했다. 눈발별 물리 충돌은 켜지 않았다. 음원0.

## 독립 평가

새 컨텍스트 평가자가 실제 화면과 기존 생성 참고 이미지를 직접 비교했다. [원문](judge.md).

- 눈발 증가: **PASS**. 323/282 두 시점 모두 뚜렷하게 많아졌고 캐릭터·길 식별 유지.
- 방향 없는 전체 화면 섬광: **PASS**. 폐허·비 오는 숲에서 전체 밝기 변화, 우측 상단 집중 제거 확인.
- 제출 이미지의 새 치명적 결함 없음. 이번 요청 범위에서는 추가 반복 없이 종료 가능.

전체 참고 이미지 일치도는 눈7.05/10, 기본 섬광6.10/10, 강한 섬광5.90/10. **이번 두 변경의 PASS는 전체 장면 Pro8점 달성과 다르다.** 섬광 순간 회색 막처럼 보이는 대비 저하, 기존 재질·식생의 참고 이미지와의 차이는 남아 있다. 최신 지시와 다른 과거 방향성을 되살리거나 전체 장면을 다시 만드는 추가 반복은 하지 않았다. 최종 취향·직접 플레이 수락은 사용자 확인이 남는다.
