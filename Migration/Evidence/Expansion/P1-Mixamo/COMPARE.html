VESPER P1 — Mixamo 모션 비교

같은 안뜰과 자동 이동 경로에서 촬영한 실제 Windows 플레이어입니다. 영상은 약10Hz 캡처이며 게임 성능 측정과 별개입니다. 두 기록의 프레임 타이밍이 달라 자세가 정확히 일치하지 않을 수 있습니다.

기존 P1

Mixamo Walking + Breathing Idle

순서: 대기 → 걷기·정지 → 방향 전환 → 나무 근처 이동 → 카메라 회전·줌 → 최대/최소 거리. 완전한 발 고정 정지 모션은 아니며 정지 때 발 재배치가 남습니다. 직접 플레이는 저장소 루트의 PLAY_VESPER_MIXAMO.cmd를 실행하세요.
